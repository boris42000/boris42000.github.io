# sarahkophg

Static one-page photography portfolio, served at
<https://boris42000.github.io/sarahkophg/>.

Hand-written HTML/CSS/JS — no framework, no runtime dependencies. It shares nothing
with the `abmaudit` project that also lives in this repo; either can be moved out
without touching the other.

## Layout

```
index.html      generated by tools/build-page.mjs — see "Editing" below
styles.css      hand-edited
main.js         hand-edited — nav, lightbox, filters, reveal, blur-up
img/            generated derivatives (committed)
fonts/          self-hosted woff2 (committed)
photos/         original masters — NOT in git
tools/          the build step (its own package.json + node_modules)
```

## ⚠️ The masters are not backed up here

`photos/` is gitignored. Those 22 originals (~150 MB) exist only on the machine that
made this site — **keep your own backup of them.** Everything in `img/` is a derived,
downsized, desaturated copy; the originals cannot be recovered from it.

## Editing

**Copy tweaks** — edit `index.html` directly. It is plain static HTML.

**Anything about the photo set** — edit the `PHOTOS` list in
`tools/optimize-images.mjs` (that list *is* the curation: 10 of the 22 masters are
published, the rest are held back as near-duplicates or off-message), then:

```sh
cd tools
npm install     # first time only
npm run build   # images + icons + index.html
```

Note that `npm run page` regenerates `index.html` from the template inside
`tools/build-page.mjs`, so it **overwrites hand-edits to that file**. If you have
edited `index.html` by hand and want to change photos too, port the copy changes into
`build-page.mjs` first.

Individual steps: `npm run images`, `npm run assets`, `npm run page`.
